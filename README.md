# Dashboard de vehículos usados

Proyecto del Sprint 7 de Ciencia de Datos de TripleTen.

## Descripción del proyecto

Esta aplicación web permite explorar anuncios de venta de vehículos usados en Estados Unidos mediante visualizaciones interactivas.

El objetivo es facilitar la exploración de los datos y comprender la distribución del kilometraje y su relación con los precios de venta.

## Funcionalidades

- **Histograma:** muestra la distribución del kilometraje de los vehículos.
- **Gráfico de dispersión:** permite visualizar la relación entre el precio y el kilometraje.
- **Botones interactivos:** permiten generar los gráficos según la selección del usuario.

## Tecnologías utilizadas

- Python
- Pandas
- Plotly
- Streamlit

## Conjunto de datos

El archivo `vehicles_us.csv` contiene los anuncios de vehículos utilizados para el análisis.

El análisis exploratorio se encuentra en `notebooks/EDA.ipynb`.
